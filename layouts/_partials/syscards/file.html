{{- /* 一个下载文件：dict "page" 中文页（文件是它的资源）"f" front matter 里的 html/pdf 项。返回 url、size。 HTML 在内容目录里存成 .html.raw（.html 会被 Hugo 当成文章），以 .html 的名字发布到 files/ 下 */ -}} {{- $f := .f }} {{- $url := "" }} {{- with .page.Resources.Get $f.file }} {{- $name := strings.TrimSuffix ".raw" (path.Base .Name) }} {{- with resources.Copy (path.Join "translations/system-cards/files" $name) . }}{{ $url = .RelPermalink }}{{ end }} {{- else }} {{- errorf "系统卡下载文件不存在：%s" $f.file }} {{- end }} {{- return dict "url" $url "size" (printf "%.1f MB" (div (float $f.bytes) 1048576)) }}
