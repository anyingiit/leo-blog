Claude Mythos 5 和 Claude Fable 5 是 Anthropic 推出的一款新大语言模型（large language model）的两种配置。前者 Mythos 5 目前仅通过 [Project Glasswing](https://www.anthropic.com/glasswing) 向负责防御全球关键软件基础设施的经审核合作伙伴提供。Fable 5 则面向全面开放发布——它与 Mythos 5 具有相同的底层模型权重，但增设了额外的安全防护措施，以防止其在网络安全和生物学方面被滥用。

### 1.1 训练数据与流程

Mythos 5 和 Fable 5 的训练数据是一种专有组合，包括来自互联网的公开信息、公开和非公开数据集，以及由其他模型生成的合成数据。在整个训练过程中，我们使用了多种数据清洗和过滤方法，包括去重和分类。

我们使用一个名为 ClaudeBot 的通用网络爬虫从公开网站获取训练数据。该爬虫遵循行业标准做法，尊重网站运营者通过“robots.txt”指令所表明的是否允许抓取其网站内容的意愿。我们不会访问受密码保护的页面，也不会访问需要登录或 CAPTCHA 验证的页面。我们会对所使用的训练数据进行尽职调查。该爬虫以透明方式运行；网站运营者可以轻松识别它何时抓取了其网页，并向我们表明他们的偏好。

预训练之后，模型经过了大量的后训练和微调，目标是使其成为一个行为符合 Claude 宪法（constitution）中所述价值观的助手。

Claude 支持多种语言，通常会使用与用户输入相同的语言进行回复。输出质量因语言而异。该模型仅输出文本。

### 1.2 众包工作者

### 1.4 模型评估

在训练过程的不同时间点，我们会获取模型的不同“快照”。除非另有说明，本系统卡（System Card）中讨论的所有评估均基于 Claude Mythos 5 或 Claude Fable 5 的最终快照。其他开发者模型的数据通常取自各开发者公布的结果或公开排行榜，但在某些情况下，我们自行运行了评估。

在本系统卡中，我们根据具体情境决定评估 Mythos 5（不带安全防护措施，反映模型的底层能力）还是 Fable 5（带安全防护措施，与全面开放后的用户体验一致）。全文都会清楚注明我们选择评估的是两者中的哪一个。

### 1.5 新型安全防护措施

除了我们的标准安全防护措施——例如针对有害化学/生物用途的 ASL-3 拦截分类器，这类分类器已随所有近期前沿模型一同部署——Claude Fable 5 在部署时还配备了多项新型安全防护措施，使我们能够安全地将其面向通用用途发布。这些新的安全防护措施是一些分类器，会在检测到与网络安全、生物学和化学、蒸馏尝试或加速前沿 AI 开发相关的话题时触发。网络安全、生物学和化学分类器背后的具体考量已在我们的[发布博客文章](https://www.anthropic.com/news/claude-fable-5-mythos-5)中说明。

我们与前沿 LLM 开发相关的新安全防护措施，源于我们[2026 年 2 月风险报告](https://anthropic.com/feb-2026-risk-report)（Risk Report）第 6.1 节中讨论的风险。我们担忧加快 AI 整体发展步伐所带来的风险，尽管我们对这些风险的严重程度仍不确定。具体而言，正如我们当时所写，我们担忧的是“加速其他 AI 开发者构建与我们的系统构成类似风险的强大 AI 系统——而这些开发者未必具备相应的安全防护措施”。使用 Claude 开发竞争模型本已违反我们的[服务条款](https://www.anthropic.com/legal/consumer-terms)，而通过分类器执行这一限制，可以避免加速那些最愿意违反这些条款的行为者。我们的分类器仅窄范围地针对前沿 LLM 开发（例如构建预训练流水线、分布式训练基础设施或 ML 加速器设计），应不会影响绝大多数 AI 开发或研究。

当 Fable 的回退（fallback）分类器被触发时，由此产生的行为取决于产品端：

- 在客户端应用（网页界面以及桌面和移动应用）中，请求会自动回退到最新的 Claude Opus 模型（发布时为 Claude Opus 4.8），并且会告知用户其查询经由哪个模型处理；
- 在 Messages API 中，默认不会自动回退。请求会被拦截，响应中会返回拒绝原因及结构化类别。开发者可以在客户端实现重试或回退逻辑，也可以选择启用自动的服务端回退，此时请求将由指定的回退模型（例如最新的 Claude Opus 模型）重新处理，且回退情况会体现在响应对象中；
- 在某些 Claude 界面中，自动回退到最新的 Claude Opus 模型是默认行为，且不可配置。每当发生回退时，都会发出一个会话事件。

为了更快推出 Fable，我们优先考虑了分类器的鲁棒性和覆盖范围，但在该模型发布后，我们将努力提升检测方法的精确率。

### 1.6 外部测试

我们对模型的大部分评估均在 Anthropic 内部进行。不过，作为我们前沿合规框架（Frontier Compliance Framework，“FCF”）的一部分，我们会委托外部评估方测试我们模型的不同迭代版本（例如未经无害性训练的版本、经过无害性训练的版本，或两个版本都测试）。他们的意见有助于我们就系统性风险领域作出风险判定，并为我们的发布决策流程提供参考。有关我们如何在 FCF 中征求外部专家意见的更多信息，请参阅我们[合规框架的第 5 节。](https://trust.anthropic.com/resources?)

我们感谢所有外部测试方对模型开展评估并与我们分享结果。他们的具体贡献将在下文中介绍。
