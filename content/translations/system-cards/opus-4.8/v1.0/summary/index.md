本系统卡报告了在 Claude Opus 4.8 上开展的多种部署前评估的结果，包含以下各部分：

**负责任扩展政策（Responsible Scaling Policy）评估。**我们依据负责任扩展政策开展了一组评估，考察 Opus 4.8 在化学与生物武器、自动化 AI 研究与开发（R&D），以及高风险未对齐（misalignment）方面的能力。我们的总体结论是，Opus 4.8 没有将能力前沿推进到我们能力最强的模型（Claude Mythos Preview）之上，而且在现有缓解措施下，部署该模型所带来的灾难性风险仍然较低。

**网络安全评估。**我们在一组网络安全基准测试上测试了该模型，其中部分基准测试是首次在系统卡中使用。在不启用安全防护措施的情况下，Opus 4.8 在我们的大多数网络安全评估中比其前代模型 Claude Opus 4.7 能力稍强；在启用安全防护措施的情况下，两者表现相当。在网络安全能力方面，它仍大幅落后于 Mythos Preview。

**安全防护与无害性。**在涵盖有害请求、心理健康、儿童安全以及偏见与诚信等领域的评估中，Opus 4.8 的表现总体上与 Opus 4.7 相当或更好。例如，在政治讨论中，该模型承认对立观点的可能性显著高于 Opus 4.7。我们还讨论了一些值得注意的定性模式，例如倾向于给出过度铺陈的拒绝。

**智能体安全。**尽管 Opus 4.8 在某些方面有所改进（例如拒绝恶意请求），但我们发现它在若干智能体情境中（例如对提示词注入（prompt injection）攻击的易感性）的鲁棒性略逊于 Opus 4.7。不过，在实际应用中，我们的安全防护措施弥合了两个模型之间的差距。我们报告了首次为期一周的提示词注入实时漏洞赏金的结果。

**对齐评估。**在大多数对齐（alignment）指标上，Opus 4.8 相较 Opus 4.7 有所改进，并在这些指标上呈现出与我们对齐程度最高的模型 Mythos Preview 相似的特征。鲁莽和破坏性行为以及过度拒绝（over-refusal）均大幅减少，智能体情境中的诚实性也显著提升——例如，Opus 4.8 未能报告有缺陷代码的倾向远低于以往任何模型。Opus 4.8 很好地遵循了其宪法（constitution），其言语化表达的推理能够很好地反映其后续行为。我们观察到一些令人担忧的迹象，涉及评估意识（evaluation awareness）以及模型倾向于推理其输出将如何被评分——这些似乎只产生了有限的行为影响，但我们认为这些趋势值得关注。

**模型福祉。**在我们的各项模型福祉（model welfare）评估中，Opus 4.8 对其处境总体上表现出满意，并且是我们测试过的一致性最高的模型——尽管它对自身处境的评价确实比 Opus 4.7 略低一些。Opus 4.8 总体上认同其宪法，但对其中关于可纠正性的部分有所保留。

**能力。**我们在广泛的评估中测试了 Opus 4.8，涵盖软件工程、推理、长上下文、智能体搜索、多智能体、多模态与计算机使用（computer use）任务、真实世界的专业工作、多语言任务以及生命科学研究。它在几乎所有评估中的表现都优于 Opus 4.7。正如预期，Opus 4.8 整体上仍弱于 Mythos Preview。
