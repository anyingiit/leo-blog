Claude Opus 4.8 是 Anthropic 推出的一款新的大语言模型（large language model）。它是对其前代模型（Claude Opus 4.7）的升级，在软件工程、智能体工具使用和知识工作任务方面的能力有所提升。这使其成为 Anthropic 迄今为止能力最强的全面开放的模型。本系统卡（System Card）报告了针对 Opus 4.8 的能力及其安全相关特性与行为的一系列评估。

### 1.1 训练数据与过程

Claude Opus 4.8 的训练数据是一个专有的混合数据集，包括来自互联网的公开信息、公开和非公开数据集，以及由其他模型生成的合成数据。在整个训练过程中，我们使用了多种数据清洗和过滤方法，包括去重和分类。

我们使用一个名为 ClaudeBot 的通用网络爬虫从公开网站获取训练数据。该爬虫在网站运营者设置的、用于表明是否允许爬取其网站内容的“robots.txt”指令方面，遵循业界标准做法。我们不会访问受密码保护的页面，也不会访问需要登录或 CAPTCHA 验证的页面。我们会对所使用的训练数据进行尽职调查。该爬虫以透明方式运行；网站运营者可以轻松识别它何时爬取了其网页，并向我们表明其偏好。

在预训练之后，Opus 4.8 经历了大量的后训练和微调，目标是使其成为一个行为符合 [Claude 宪法](https://www.anthropic.com/constitution)（Claude's constitution）中所述价值观的助手。

Claude 支持多种语言，通常会使用与用户输入相同的语言进行回复。输出质量因语言而异。该模型仅输出文本。

### 1.4 迭代式模型评估

在训练过程中的不同时间点会获取模型的不同“快照”。训练期间还存在模型的不同版本，包括不含任何安全防护措施的“仅有用（helpful only）”版本。除非另有说明，本系统卡中讨论的所有评估均针对模型的最终快照，并且包含安全防护措施。
