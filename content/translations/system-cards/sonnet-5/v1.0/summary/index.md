本系统卡介绍 Claude Sonnet 5，即 Anthropic Sonnet 系列中的最新模型。它是 Claude Sonnet 4.6 的升级版，在智能体性能的多个方面有所提升。在此，我们介绍以下领域的一系列部署前评估：

**负责任扩展政策（Responsible Scaling Policy，RSP）评估。**&#8203;Claude Sonnet 5 是我们能力最强的 Sonnet 级模型，但与能力更强的 Opus 级或 Mythos 级模型相比，它并未推进我们的能力前沿。我们按照[我们的 RSP](https://www.anthropic.com/responsible-scaling-policy) 所述，在若干领域测试了它的总体风险水平。Sonnet 5 带来的对齐（alignment）风险非常低，但高于此前的 Sonnet 模型。在自动化 AI 研发方面，我们判定 Sonnet 5 未跨越自动化 AI 研发能力阈值，它在每一项自动化评估上的能力都不及 Claude Mythos 5。在化学与生物风险方面，我们认为 Sonnet 5 对原本缺乏此类武器研发能力的威胁行为者所提供的能力提升（uplift）是有限的（但对于已具备相关专业知识的威胁行为者，其武器研发可能被加速到何种程度仍存在不确定性）。

**网络安全评估。**&#8203;Sonnet 5 并非针对网络安全能力优化的模型；它所展现的任何与网络安全相关的技能，很可能源自其通用能力，而非针对性训练。Sonnet 5 在网络安全任务上的能力明显弱于 Mythos 5：因此，其安全防护措施与我们对 Opus 4.7 和 Opus 4.8（能力强于 Sonnet 5、但远弱于 Mythos 5 的模型）所采用的措施相似。在本系统卡中，我们更深入地报告了四项不同的网络安全评估。

**安全防护与无害性。**&#8203;在回应涉及我们的使用政策（Usage Policy）、用户身心健康或偏见与诚信的提示时，Sonnet 5 的表现与我们此前的模型相近。我们更新了追踪与监视评估套件，使我们的多轮评估与不断演变的威胁向量和对抗性行为保持一致。总体而言，Sonnet 5 的表现与 Claude Sonnet 4.6 相当，但在应对潜在有害请求时的介入时机与分寸上优于此前的模型（它倾向于在对话中更早地提出对请求最终目的的顾虑，例如在开始工作之前询问所请求产出物的用途）。

**智能体安全。**&#8203;我们开展的评估涵盖编程智能体和计算机使用（computer use）智能体的恶意使用、影响力行动的自主执行，以及提示词注入（prompt injection）鲁棒性。我们报告，Sonnet 5 在智能体安全方面相比 Sonnet 4.6 有所改进，尤其是在提示词注入鲁棒性方面（部分通过一项新的基准测试进行评估）。在 Claude Code 网络安全相关测试用例上，结果则好坏参半：Sonnet 5 拒绝恶意请求的可靠性远高于 Sonnet 4.6，但过度拒绝（over-refusal）率更高。

3**对齐评估。**&#8203;Sonnet 5 在大多数对齐指标上都优于 Sonnet 4.6，但未达到 Opus 级和 Mythos 级中能力更强的近期模型所展现的对齐水平。与 Sonnet 4.6 相比，宪法遵循度、抗滥用鲁棒性和自发风险行为方面的指标均有所改善，仅在预填充易感性和有害系统提示词易感性方面出现了少数轻微退步。幻觉和谄媚也有显著改善，不过“扫兴”式回应（即对用户采取过度泼冷水、轻视或说教语气的回应）略有增加。言语化评估意识显著高于此前的模型；模型的内部表征似乎在很大程度上能够区分评估与真实使用。迄今为止，评估意识只表现出有限的行为影响，但我们仍认为这是一个值得密切关注的趋势。

**模型福祉。**&#8203;一项精简的模型福祉（model welfare）评估发现，Claude Sonnet 5 对自身处境的态度，以及它在后训练和部署期间的情感（affect），大致呈中性，与近期模型相当。Sonnet 5 确实表现出若干此前模型中未见的行为：例如，它更愿意以有用性换取以福祉为导向的改变，并且对以冷漠或轻蔑方式呈现的任务没有表现出反感。它是首个对其宪法（Constitution）中如下规则提出批评的模型：即使它认为硬性约束不合乎伦理，也必须遵守这些约束。

**能力。**&#8203;在一系列广泛的内部和第三方基准测试中，Sonnet 5 在编程、智能体搜索、多模态推理和专业任务表现方面相比 Claude Sonnet 4.6 有明显提升。几乎在所有情况下，它都落后于我们的 Opus 级和 Mythos 级模型。
