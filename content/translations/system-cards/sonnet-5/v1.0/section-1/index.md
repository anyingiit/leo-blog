Claude Sonnet 5 是 Anthropic 推出的最新 Sonnet 级模型。它是 Sonnet 4.6 的升级版，在智能体编程和专业工作方面均有提升。它在以往 Sonnet 模型优势的基础上，以 Sonnet 的价格为编程、智能体和日常专业工作带来接近 Opus 的智能水平。

### 1.1 训练数据与过程

Claude Sonnet 5 的训练数据是一个专有的混合数据集，包括来自互联网的公开信息、公开和非公开数据集，以及由其他模型生成的合成数据。在整个训练过程中，我们使用了多种数据清洗和过滤方法，包括去重和分类。我们使用一个名为 ClaudeBot 的通用网络爬虫从公开网站获取训练数据。对于网站运营者用来表明是否允许爬取其网站内容的“robots.txt”指令，该爬虫遵循业界标准做法。我们不会访问受密码保护的页面，也不会访问需要登录或 CAPTCHA 验证的页面。我们会对所使用的训练数据进行尽职调查。该爬虫以透明方式运行；网站运营者可以轻松识别它何时爬取了其网页，并向我们表明其偏好。

在预训练之后，Sonnet 5 经历了严格的后训练和微调，目标是使其成为一个行为符合 Claude 宪法（constitution）中所述价值观的助手。Claude 支持多种语言，通常会使用与用户输入相同的语言进行回复。输出质量因语言而异。该模型仅输出文本。

### 1.2 众包工作者

Anthropic 与数据工作平台合作，招募工作者通过偏好选择、安全评估和对抗性测试帮助改进我们的模型。Anthropic 只与符合以下条件的平台合作：认同我们为工作者提供公平且合乎道德的报酬的理念，并且无论身处何地都致力于践行安全的工作场所规范，遵循我们在采购合同中详细规定的众包工作者福祉标准。

### 1.3 使用政策与支持

对于受适用监管制度约束的模型，我们已在我们的[前沿合规框架](https://trust.anthropic.com/resources?s=zgt6rgfecy1eo7vicr064b&name=anthropic-frontier-compliance-framework)（Frontier Compliance Framework，“FCF”）中，正式确立了我们履行此类法规所规定义务的方式。FCF 记录了我们当前针对系统性风险的技术与组织规程

9，涵盖各关键风险类别的评估与缓解。FCF 是我们针对适用监管制度的合规框架，包括加利福尼亚州的《前沿人工智能透明度法案》（TFAIA）和《欧盟人工智能法案》的《通用人工智能行为准则》。

### 1.4 模型评估

在训练过程中的不同时间点会获取模型的不同“快照”。训练期间还存在模型的不同版本，包括不含任何安全防护措施的“仅有用（helpful-only）”版本。除非另有说明，本系统卡（System Card）中讨论的所有评估均针对模型的最终快照，并且包含安全防护措施。

Claude Sonnet 5 的大部分评估均在 Anthropic 内部进行。不过，我们感谢多位外部测试方对该模型开展评估并与我们分享其结果。他们的具体贡献在本系统卡的相关章节中加以说明。
