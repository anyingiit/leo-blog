Claude Opus 4.7 是 Anthropic 推出的一款新的大语言模型（large language model），在软件工程、知识工作、智能体工具使用以及计算机使用（computer use）等领域具备尤为突出的能力。在本系统卡（System Card）中，我们报告了覆盖面极广的一系列评估的结果，涉及该模型的能力及其安全概况。

### 1.1 模型训练与特性

#### 1.1.1 训练数据与过程

Claude Opus 4.7 的训练数据是一个专有的混合数据集，包括来自互联网的公开信息、公开和非公开的数据集，以及由其他模型生成的合成数据。在整个训练过程中，我们使用了多种数据清洗和过滤方法，包括去重和分类。

我们使用一款名为 ClaudeBot 的通用网络爬虫从公开网站获取训练数据。该爬虫遵循业界标准做法，尊重网站运营者通过“robots.txt”指令表明的是否允许爬取其网站内容的意愿。我们不会访问受密码保护的页面，也不会访问需要登录或 CAPTCHA 验证的页面。我们会对所使用的训练数据进行尽职调查。该爬虫以透明的方式运行；网站运营者可以轻松识别它何时爬取了其网页，并向我们表明其偏好。

在预训练过程之后，Opus 4.7 经过了大量的后训练和微调，目标是使其成为一个行为与 Claude 的[宪法（constitution）](https://www.anthropic.com/constitution)中所述价值观相一致的助手。

Claude 支持多种语言，通常会使用与用户输入相同的语言进行回应。输出质量因语言而异。该模型仅输出文本。

#### 1.1.2 众包工作者

Anthropic 与数据工作平台合作，聘用工作者通过偏好选择、安全评估和对抗性测试来帮助改进我们的模型。Anthropic 只与认同我们信念的平台合作——即为工作者提供公平且合乎道德的报酬——并且这些平台须承诺无论身处何地都采用安全的工作场所做法，遵循我们在采购合同中详细规定的众包工作者福祉标准。

#### 1.1.4 迭代式模型评估

在训练过程的不同时间点会获取模型的不同“快照”。训练期间还存在模型的不同版本，包括一个不含任何安全防护措施的“仅有用（helpful only）”版本。除非另有说明，本系统卡中讨论的所有评估均来自模型的最终快照，并且包含安全防护措施。

#### 1.1.5 外部测试

我们非常感谢多位外部测试方对 Claude Opus 4.7 开展部署前评估。该模型在多个风险领域接受了评估，包括网络安全、失控、CBRN 和有害操纵，我们已将这些评估的结果纳入整体风险评估之中。

#### 1.2.2 RSP 决策

根据我们的[负责任扩展政策（Responsible Scaling Policy）](https://www.anthropic.com/responsible-scaling-policy)，我们会定期发布全面的风险报告（Risk Report），阐述我们模型的安全概况。而如果我们发布的模型比上一份风险报告中讨论的模型“能力显著更强”，我们必须“（在我们的系统卡中或其他地方）发布讨论，说明该模型的能力和倾向如何影响或改变风险报告中的分析”。对于风险报告更新，我们通常遵循与管理风险报告相同的内部流程。

Claude Opus 4.7 的能力显著强于 Claude Opus 4.6——后者是我们最近一份风险报告中所讨论的能力最强的模型。尽管能力有所提升，我们的总体结论是灾难性风险仍然较低：

- **非新型化学与生物武器的生产。**Claude Opus 4.7 的能力强于 Claude Opus 4.6，但就我们整体风险评估的目的而言，其风险特征实际上相似。我们认为，我们的风险缓解措施足以使非新型化学/生物武器生产带来的灾难性风险处于非常低但并非可忽略的水平。
- **新型化学与生物武器的生产。**我们认为，新型化学/生物武器带来的灾难性风险仍然较低（但存在相当大的不确定性）。整体情况与我们最近一份风险报告中的情况相似。
- **未对齐模型带来的风险。**我们认为总体风险非常低，而且该模型本身对我们此前针对 [Claude Mythos Preview](https://www-cdn.anthropic.com/79c2d46d997783b9d2fb3241de43218158e5f25c.pdf) 所阐述的风险图景几乎没有增加什么。
- **关键领域的自动化研发。**该模型的能力介于 Claude Opus 4.6 与 Claude Mythos Preview 之间，并未推进我们的能力前沿。我们认为，Claude Opus 4.7 不会改变我们在[最近一份风险报告](https://www-cdn.anthropic.com/08eca2757081e850ed2ad490e5253e940240ca4f.pdf)中针对这一威胁模型所呈现的图景。
