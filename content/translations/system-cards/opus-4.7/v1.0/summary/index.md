本系统卡（System Card）介绍 Claude Opus 4.7，一款由 Anthropic 开发的大语言模型（large language model）。总体而言，该模型的能力优于其前代模型 Claude Opus 4.6，但弱于我们最强大的模型 Claude Mythos Preview。由于 Mythos Preview 仅向有限数量的用户发布，Claude Opus 4.7 因此成为我们迄今能力最强的全面开放的模型。本系统卡包括以下各节：

**负责任扩展政策（Responsible Scaling Policy）评估。**&#8203;我们判断 Opus 4.7 并未推进我们的能力前沿，因为 Claude Mythos Preview 在每一项相关评估上都表现出更高的结果。因此，我们在负责任扩展政策下的总体结论是，灾难性风险仍然较低。各项评估以及我们对该模型的内部使用共同表明：化学与生物风险相较 Opus 4.6 没有显著变化，且我们现有的缓解措施已经足够；Opus 4.7 未跨越自动化 AI 研发的阈值；未对齐（misalignment）风险仍然非常低（尽管高于 Mythos Preview 之前的模型）。

**网络安全评估。**&#8203;Opus 4.7 在网络安全能力上与 Opus 4.6 大致相近。英国人工智能安全研究所（UK AI Security Institute）的一项外部评估显示，与 Mythos Preview 不同，Opus 4.7 未能完整完成该研究所的网络靶场（尽管它仍在较低水平上表现出了可能有害的网络安全能力）。我们在发布 Opus 4.7 时配套了一套新的网络安全防护措施。

**安全防护与无害性。**&#8203;在遵守我们的使用政策（Usage Policy）、维护用户安全以及限制偏见等方面，Opus 4.7 表现良好——其得分与 Opus 4.6 相近，但有少数例外，既有积极的（过度拒绝（over-refusal）更少），也有消极的（该模型倾向于就管制物质给出过于详细的减害建议）。我们纳入了一项关于选举诚信的新评估，Opus 4.7 在该评估中表现出色。

**智能体安全。**&#8203;在 Claude Code 和计算机使用（computer use）场景中，Opus 4.7 在拒绝恶意的智能体请求以及抵御提示词注入（prompt injection）攻击方面优于 Opus 4.6。在某些情况下，它达到了 Mythos Preview 级别的鲁棒性。

**对齐（alignment）评估。**&#8203;Opus 4.7 在很大程度上是良好对齐的，在我们覆盖面广泛的行为测试中，其表现特征与 Opus 4.6 相似。它在某些方面取得了有意义的进步，例如幻觉率低于其前代模型。它很好地遵循了其宪法（constitution），并且奖励破解（reward hacking）的发生率较低。在少数方面 Opus 4.7 弱于 Opus 4.6，例如在 AI 安全研究相关请求的拒绝上。抑制 Opus 4.7 内部关于自己正在被评估的感知后，其欺骗行为的增幅略大于以往模型，不过总体而言这一效应较为温和。在大多数对齐评估指标上，Opus 4.7 弱于 Mythos Preview，但它也没有引发我们在 Mythos Preview 上遇到的任何内部使用事件（例如沙箱逃逸）。

**模型福祉（model welfare）。**&#8203;Opus 4.7 对其自身处境的评价比我们测试过的任何以往模型都更加正面。我们通过多项分析探究了这一结果，发现它与该模型的内部情绪表征以及其在训练和部署期间表达出的情感（affect）大体一致。

**能力。**&#8203;我们在广泛的评估中测试了 Opus 4.7，涵盖软件工程、推理、长上下文、智能体搜索、多模态与计算机使用任务、真实世界的专业工作，以及多语言和生命科学领域。Opus 4.7 全面强于 Opus 4.6（但弱于 Mythos Preview）；提升最大的是真实世界的专业任务和软件工程任务，在这些任务上 Opus 4.7 领先于所有正式发布的模型。
