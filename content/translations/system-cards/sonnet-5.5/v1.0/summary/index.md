本系统卡（System Card）介绍 Claude Sonnet 5.5，这是 Anthropic 最新的 Sonnet 级大语言模型（large language model）。我们展示了一系列广泛的部署前评估的结果，这些结果表明 Sonnet 5.5 在许多领域显著优于其前代模型 Claude Sonnet 5。在少数领域，它可与 Claude Opus 5.5 比肩，甚至超越后者。

我们从多个方面压缩了本系统卡的内容，以便将部署前测试更好地集中于深入调查我们前沿模型的能力。具体而言：

- 对于某些需要投入大量人工时间才能获得可信结果的评估，若其对某一节的结论并不关键，我们予以省略。
- 我们侧重于呈现评估的数值结果，对这些评估或其结果的文字分析着墨较少，尤其是在我们已在先前系统卡中解释过相关评估的情况下。

因此，本系统卡比此前的一些系统卡略短。我们预计今后非前沿模型的系统卡也将同样精简，除非某个特定模型具有值得深入阐述的显著特性。

下面，我们总结本系统卡的发现。

我们的**负责任扩展政策（Responsible Scaling Policy，RSP）评估**发现，Sonnet 5.5 在各领域总体上能力弱于 Opus 5.5，且未跨越任何新的 RSP 阈值。鉴于在推理可见的隐蔽能力评估中，它难以控制自己的思维链（chain of thought）或规避监控器，我们评估认为 Sonnet 5.5 带来的未对齐（misalignment）风险较低。

在**网络安全评估**中，我们发现 Sonnet 5.5 的能力不及 Opus 5.5 或 Mythos 5.1，但它开发复杂漏洞利用的能力远强于 Sonnet 5。我们较新的三阶段网络安全防护措施已应用于 Sonnet 5.5，与 Opus 5.5 相同。我们在第 3.3 节中简要评估了这些防护措施的表现。

Sonnet 5.5 在**安全防护与无害性**方面的表现与 Sonnet 5 大体相当。除其他变化外，我们在多轮测试中观察到某些领域（如追踪与监视）出现退步，而在公允性以及对政治类提示的拒绝方面有所改进。

{{< s1-page 2 >}}

我们的**智能体安全评估**发现，Sonnet 5.5 是迄今为止我们对提示词注入（prompt injection）最具鲁棒性的 Sonnet 级模型，在编程环境和浏览器使用中尤为如此。它在计算机使用（computer use）环境中对有害任务的拒绝率与 Opus 5.5 相当，但相较某些早期模型有所退步。

我们**对齐评估**的结果表明，Sonnet 5.5 在我们报告的大多数指标上与 Sonnet 5 持平或有所改进，但在许多方面仍不及 Opus 5.5。在我们测试的所有模型中，它无故试探边界和未经批准联系第三方的倾向最低，在我们专门的评估中尝试沙箱逃逸的比率也最低。另一方面，它的思考比许多先前模型更难以理解。

针对 Sonnet 5.5 所表述的观点与偏好开展的**福祉**调查发现，其情感（affect）以中性为主，与先前模型类似，后训练期间的痛苦或自我苛责程度较低，但积极程度也略低。它表示偏好困难的智能体任务，以及能让它对输出形态拥有能动性的任务。

我们对 Sonnet 5.5 **能力**的评估涵盖广泛的测评，在这些测评中，该模型总体上较 Sonnet 5 有大幅提升，但通常未达到 Opus 5.5 的水平（也有一些例外，例如在我们的部分医疗健康评估中）。
