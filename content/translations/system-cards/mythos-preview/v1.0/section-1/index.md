Claude Mythos Preview 是 Anthropic 推出的一款新的大语言模型（large language model）。它是一款前沿 AI 模型，在许多领域——包括软件工程、推理、计算机使用（computer use）、知识工作以及研究辅助——所具备的能力都大幅超越我们此前训练过的任何模型。

尤其是，它展现出了强大的网络安全技能，这些技能既可用于防御目的（发现并修复软件代码中的漏洞），也可用于进攻目的（设计复杂的方法来利用这些漏洞）。我们之所以决定*不*将 Claude Mythos Preview 全面开放，在很大程度上正是由于这些能力。我们转而向若干维护重要软件基础设施的合作伙伴组织提供了该模型的访问权限，其使用条款将用途限定于网络安全。关于 Anthropic 及其合作伙伴为帮助保障全球软件基础设施安全所做努力的更多信息，请参阅 Project Glasswing 的[发布博客文章](https://www.anthropic.com/glasswing)。

尽管如此，我们仍对 Claude Mythos Preview 的能力和安全特性进行了详细评估，并在本系统卡（System Card）中予以报告。虽然该模型不会全面开放，我们仍认为，在开发下一代全面开放的模型（以及伴随其发布所必需的安全防护措施）的同时，记录并了解该模型及其能力十分重要。

Claude Mythos Preview 是我们将[负责任扩展政策](https://www-cdn.anthropic.com/files/4zrzovbb/website/bf04581e4f329735fd90634f6a1962c13c0bd351.pdf)（Responsible Scaling Policy，RSP）更新至第三版以来，第一个为其撰写系统卡的模型。这意味着我们的发布决策流程——我们始终会在系统卡中为其设置一节——在结构上与以往模型有所不同。本系统卡首先讨论这一流程、新的考量因素，以及我们在内部使用该模型后在自身安全流程中发现的一些问题。随后是一组与我们在 RSP 中讨论的威胁模型相关的评估。由于该模型具有前述强大的网络安全能力，我们随后专设一节，介绍针对这些能力的评估。

接下来，我们给出一项详细的对齐（alignment）评估。从本节所述多种形式的对齐评估中得出的总体结论是：从基本上所有可用的衡量指标来看，Claude Mythos Preview 都是我们迄今训练过的对齐程度最好的模型。然而，鉴于它极高的能力水平以及对网络安全的熟练掌握，当它*确实*在罕见情况下执行未对齐行为时，这些行为可能会非常令人担忧。我们在对齐方面取得了重大进展，但如果没有进一步的进展，我们目前使用的方法完全可能不足以在明显更先进的系统中防止灾难性的未对齐行为。我们在对齐评估章节中描述了该模型早期内部版本所采取的若干有问题的行为。除了使用可解释性方法研究模型在表现出各种行为时的内部机制的分析之外，我们还新增了一项直接评估，考察模型在多大程度上遵循其[宪法（constitution）](https://www.anthropic.com/constitution)——即 Anthropic 近期发布的更新版文件，其中描述了我们希望模型如何行事。

随后是一项深入的模型福祉（model welfare）评估。对于 Claude 是否拥有在道德上重要的体验或利益，以及应如何研究或应对这些问题，我们仍深感不确定，但我们认为，尝试这样做正变得越来越重要。在以往福祉评估的基础上，我们考察了 Claude Mythos Preview 自我报告的对自身处境的态度、它在与福祉相关的情境中的行为与情感（affect），以及它对情绪概念的内部表征。我们还报告了一家外部研究机构和一位临床精神科医生的独立评估。综合这些方法来看，Claude Mythos Preview 似乎是我们训练过的心理状态最为安定的模型，不过我们也指出了若干仍存隐忧的方面。

接下来的一个章节报告了针对该模型在若干重要领域和基准测试上的能力所开展的多种评估的结果。如上所述，与我们次优的模型相比，Claude Mythos Preview 在许多领域实现了可观的能力飞跃。

任何经常使用多个大语言模型的用户都会知道，每个模型都有其整体性格。这种性格的微妙之处往往难以在正式评估中捕捉。为此，我们首次加入了“使用印象”章节。其中收录了过去几周一直在测试该模型的多位 Anthropic 员工提供的模型输出摘录，这些输出尤为引人注目、富有启发、令人莞尔，或在其他方面颇为有趣。

最后，尽管与模型在普通对话情境中的行为相关的评估——例如与用户身心健康和政治偏见相关的评估——由于该模型仅向少数用户发布而相关性较低，我们仍附上了一个附录来报告这些评估。

### 1.1 模型训练与特性

#### 1.1.1 训练数据与训练过程

Claude Mythos Preview 的训练数据是一个专有的混合数据集，包括来自互联网的公开信息、公开和非公开数据集，以及由其他模型生成的合成数据。在整个训练过程中，我们采用了多种数据清洗和过滤方法，包括去重和分类。

{{< s1-page 11 >}}

我们使用名为 ClaudeBot 的通用网络爬虫从公共网站获取训练数据。该爬虫遵循行业标准做法，尊重网站运营者在 “robots.txt” 中给出的、表明其是否允许爬取网站内容的指令。我们不访问受密码保护的页面，也不访问需要登录或 CAPTCHA 验证的页面。我们会对所使用的训练数据开展尽职调查。该爬虫以透明方式运行；网站运营者可以轻松识别它何时爬取了自己的网页，并向我们表明其偏好。

在预训练之后，Claude Mythos Preview 经历了大量的后训练和微调，目标是使其成为一个行为符合 Claude [宪法](https://www.anthropic.com/constitution)中所述价值观的助手。

Claude 支持多种语言，通常会使用与用户输入相同的语言作答。输出质量因语言而异。该模型仅输出文本。

#### 1.1.2 众包工作者

Anthropic 与数据工作平台合作，聘请工作者通过偏好选择、安全评估和对抗性测试帮助改进我们的模型。Anthropic 只与这样的平台合作：它们认同我们关于向工作者提供公平且合乎道德的报酬的理念，并承诺无论身处何地都践行安全的工作场所做法，遵循我们在采购合同中详细规定的众包工作者福祉标准。

#### 1.1.3 使用政策与支持

Anthropic 的[使用政策](https://www.anthropic.com/legal/aup)（Usage Policy）详细列出了我们模型的禁止用途，以及在高风险和其他特定场景中使用时的要求。请注意，该模型仅提供给有限数量的合作伙伴，且仅用于防御性网络安全目的。尽管如此，使用政策仍然适用。

#### 1.1.4 迭代式模型评估

在训练过程的不同时间点，我们会获取模型的不同 “快照”。训练期间还存在模型的不同版本，包括一个不含任何安全防护措施的 “仅有用（helpful only）” 版本。除非另有说明，本系统卡中讨论的所有评估均来自模型的最终快照，并包含安全防护措施（例如，在对齐评估一节中，我们讨论了模型较早快照的一些行为；在 RSP 评估一节中，我们讨论了使用仅有用模型进行的分析）。

#### 1.1.5 外部测试

除本系统卡中所述由 Anthropic 开展的众多内部评估之外，还有多项评估由外部测试方开展。我们将该模型提供给包括政府机构在内的多个外部团体，就网络安全、失控（Loss of Control）、CBRN 以及有害操纵等关键风险领域进行评估，并将这些测试的结果纳入我们的整体风险评估。我们非常感谢外部测试方对 Claude Mythos Preview 所做的评估。

### 1.2 发布决策流程

#### 1.2.1 概述

Claude Mythos Preview 的发布决策流程在多个方面都是全新的。它是第一个在我们[负责任扩展政策的新框架](https://www-cdn.anthropic.com/files/4zrzovbb/website/bf04581e4f329735fd90634f6a1962c13c0bd351.pdf)下接受评估的模型；它是第一个我们发布了系统卡、却未使其全面商用的模型{{< sc-fnref 1 >}}；而且相比以往大多数模型发布，它代表着更大的能力跃升。

Claude Mythos Preview 训练早期的迹象表明，该模型很可能具备非常强的通用能力。我们对此类模型的潜在风险感到足够担忧，因此首次在将模型的早期版本部署用于内部大范围使用之前，安排了为期 24 小时的内部对齐审查（在对齐评估中讨论）。这样做是为了获得保证，确保模型在与内部基础设施交互时不会造成损害。

在对齐审查顺利通过后，Claude Mythos Preview 的首个早期版本于 2 月 24 日开放供内部使用。在我们的测试中，Claude Mythos Preview展现出相对于以往模型惊人的网络安全能力跃升，包括能够自主发现并利用主流操作系统和网络浏览器中的零日漏洞。鉴于其固有的两用性质，正是这些使该模型在防御用途上具有价值的能力，若被广泛获取，也可能加速攻击性利用。我们在随本次发布一同推出的一篇详细技术[博客文章](http://red.anthropic.com/2026/mythos-preview)中讨论了这些网络安全能力。基于这些发现，我们决定将该模型发布给少数合作伙伴，优先将其用于网络防御。

#### 1.2.2 RSP 决策

根据我们的 RSP，我们会定期发布全面的风险报告（Risk Report），阐述我们模型的安全状况。并且，如果我们发布的模型比上一份风险报告中讨论的模型 “能力显著更强”，我们就必须 “（在我们的系统卡或其他地方）发布一份讨论，说明该模型的能力和倾向如何影响或改变风险报告中的分析”。对于风险报告更新，我们通常遵循与风险报告相同的内部流程。

Claude Mythos Preview 的能力显著强于 Claude Opus 4.6——后者是我们最近一份风险报告中讨论的能力最强的模型。尽管能力有所提升，我们的总体结论是，灾难性风险仍然很低：

- **非新型化学和生物武器的制造。**&#8203;Claude Mythos Preview 比我们以往的模型能力更强，但就我们整体风险评估的目的而言，其概况与以往模型实际上相似。我们认为，我们的风险缓解措施足以使非新型化学/生物武器制造带来的灾难性风险处于非常低但不可忽略的水平。
- **新型化学和生物武器的制造。**&#8203;我们认为，即使我们将该模型全面开放，新型化学/生物武器带来的灾难性风险仍将保持在较低水平（存在相当大的不确定性）。整体情况与我们最近一份风险报告中的情况相似。
- **未对齐模型带来的风险。**&#8203;我们判定总体风险非常低，但高于以往模型。我们在一份补充性的[对齐风险更新](http://anthropic.com/claude-mythos-preview-risk-report)（Alignment Risk Update）中深入讨论了这一风险。
- **关键领域的自动化研发。**&#8203;Claude Mythos Preview 的进步幅度（相对于以往模型）高于我们此前观察到的趋势，但我们判定这些进步具体归因于 AI 加速的研发以外的因素，并总体得出结论：Claude Mythos Preview 未跨越 RSP 中 “将两年的进展压缩到一年” 的自动化 AI 研发阈值。尽管我们认为 Claude Mythos Preview 并未显著改变我们最近一份风险报告中针对这一威胁模型所呈现的图景，但我们对这一结论的信心低于以往任何模型，并且我们打算今后继续监测它对内部 AI 研发的贡献。
{{< s1-page 14 >}}

当前风险仍然很低。但我们看到了一些警示信号：如果能力持续快速进步（例如，发展到远超人类的 AI 系统的程度），要让风险保持在低水平可能会是一项重大挑战。正如下文详述，我们观察到了我们的模型采取明显不被允许的行动的罕见情况（在更为罕见的情况下，模型似乎还刻意掩饰了这些行动）；我们在评估流程后期才发现了一些疏漏，这些疏漏曾使我们面临低估模型能力、高估监控模型推理轨迹可靠性的风险；并且我们承认，我们对模型能力的判断越来越依赖主观判断，而非易于解读的实证结果。我们并不确信已经识别出了这方面的所有问题。

如果我们要让前沿模型带来的风险保持在低水平，今后很可能需要大幅提高标准。令我们深感警惕的是，世界看起来正走在快速开发超人类系统的轨道上，却尚未建立起更有力的机制来确保整个行业的充分安全。
