本系统卡介绍 Claude Mythos Preview，这是 Anthropic 推出的一款大语言模型（large language model）。Claude Mythos Preview 是我们迄今能力最强的前沿模型，与我们上一代前沿模型 Claude Opus 4.6 相比，它在许多评估基准测试上的得分呈现出显著的飞跃。

本系统卡评估了该模型的能力，并报告了许多详细的安全评估。内容涵盖与我们的负责任扩展政策（Responsible Scaling Policy）和前沿合规框架（Frontier Compliance Framework）相关的测试、网络安全技能测试、一项范围广泛的对齐（alignment）评估、一项模型福祉（model welfare）评估，以及一个新增的、以定性内容为主的章节，描述用户使用该模型的体验。

Claude Mythos Preview 能力的大幅提升促使我们决定不将其全面开放使用。相反，我们正将其用于一项与有限数量合作伙伴共同开展的防御性网络安全计划。本系统卡中描述的研究发现将为未来 Claude 模型的发布及其相关安全防护措施提供参考。
