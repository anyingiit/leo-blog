# 短片

短片是用 Claude 做的自包含 HTML 动画（例如《Anthropic 的钱与权》：SVG 画面 + 逐句配音）。它们原样放进博客，不需要特殊格式；博客负责封面、放映窗口、播放器所在的文章和深浅色。

## 放进一部短片

1. **短片文件**：把短片目录整个放到 `assets/films/<名字>/`。`index.html` 是入口，它引用的配音、图片等按原来的相对路径放在同一目录里。再放一张 `poster.png`（或 `.jpg`）当封面，16:9，建议 1600×900；短片有英文版时再放一张 `poster.en.png`，英文页用它。
2. **短片的文章**：一部短片有一篇自己的文章（通常是短文，`content/notes/<slug>/index.md` 和 `index.en.md`），看片和读文字稿都在这一篇里。front matter 加：

   ```yaml
   film: <名字>         # 这篇就是这部短片的文章
   minutes: 14          # 片长，显示在封面卡片上
   filmLang: zh         # 短片本身的语言；页面语言不同时，播放地址带 ?lang=<页面语言>
   ```

   正文依次是：一段导语，`<!--more-->`，`{{< film name="<名字>" >}}`（在这篇里显示为宽幅播放器和章节目录），来源和免责声明，然后是完整文字稿（`## 文字稿 {#transcript}` 下按章节 `###`，章节顺序和短片一致；英文页写 `## Transcript {#transcript}`）。英文页翻译文字稿，这样不懂中文的读者也能读懂短片。`minutes` 两种语言可以不同（英文配音通常更长）。
3. **在别的文章里引用**：同样写 `{{< film name="<名字>" >}}`，显示为封面卡片（封面、短片文章的标题、时长），下面是「播放短片」和「阅读文字稿」两个按钮。

## 英文版和配音

英文页的播放地址带 `?lang=en`。短片自己读这个参数，换成英文画面、字幕和配音；不认这个参数的短片照常放原版，文字稿仍是英文。《Anthropic 的钱与权》的做法：画面文字过一张中英对照表（`EN`，太长的条目带缩放系数），字幕换成英文，配音从 `narration/en/` 读，每句时长按各自的配音文件。

配音用语音合成时，**直接放引擎输出的文件，不要再压缩**（例如 edge-tts 的 24 kHz MP3），转码只会更差。整部短片的配音几 MB，远低于单个文件 25 MiB 的上限。

## 读者看到的

- **短片的文章**：导语，然后是宽幅播放器（最宽 1000px，比正文宽；整个播放器放得进一屏，矮窗口如手机横屏时铺满宽度），画好之前显示封面，开播前画面左侧有一个大播放按钮。下面是折叠的章节目录（标题旁写章数和时长），每章右边是开始时间和「从这里播放」（▶），再往下是来源和文字稿。没有脚本时播放器位置显示封面。
- **短文列表里**：短片的文章只显示导语和封面卡片（播放器和文字稿在文章页），卡片下是「播放短片」和「阅读文字稿」。
- **封面卡片**（列表里，或者别的文章引用时）：「播放短片」和封面做同一件事：有脚本时在全窗口对话框里放映，没有脚本（包括 RSS 阅读器）时就是指向短片文章的普通链接；Ctrl/⌘/Shift 点击、中键照常在新标签打开。「阅读文字稿」到短片文章的 `#transcript`。封面不进 Tab 顺序，键盘只停在两个按钮上。
- **全窗口对话框**：读者已经点过播放，所以带 `?autoplay=1` 打开，焦点交给画面，空格和方向键直接可用；短片加载完之前先显示封面；放映时后面的页面不滚动。博客记住看到第几句（sessionStorage），再打开时带 `?at=` 接着放；放完时整个画面盖上「重看」「文字稿」。顶栏在 DOM 里排在画面后面，从短片里按 Tab 出来就是「文字稿」和关闭按钮。返回键、Esc、关闭按钮都关掉对话框、留在原处，焦点回到「播放短片」；关闭时移除短片，声音随之停止；每次放映都换一个新的 iframe，返回键始终按一下就关。顶栏是和画面一样的深色，右侧的「文字稿」去短片文章的文字稿，并顶替掉对话框那条历史记录，从那里按返回直接回到原处。
- 以前的短片页地址 `/films/<名字>/` 用 `aliases` 跳到短片的文章。

## 博客和短片之间的约定

短片在**沙箱 iframe** 里运行（`sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox allow-presentation"`，没有 `allow-same-origin`），和博客不同源，碰不到博客的页面和存储。构建时 `layouts/_partials/film.html` 只在 `index.html` 的 `<head>` 开头插入三样东西，其余一字不改：

- `<meta name="robots" content="noindex">` 和指向短片文章的 canonical：搜索引擎收录文章，不收录裸播放器；
- 桥接脚本 `assets/js/film-bridge.js`，经 postMessage 交换：
  - 博客 → 短片：`{type:"film:theme", theme}`，设到短片的 `<html data-theme>`；
  - 短片 → 博客：`film:ready`、`film:size`（`<html>` 的高度，文章里的播放器据此撑开）、`film:escape`（短片里按了 Esc）。
  - 短片自己可以再发（可选）：`film:progress`（`cue`：当前第几句）、`film:ended`（放完了）、`film:playing`（开播了，博客收起画面上的大播放按钮）、`film:chapters`（`starts`：每章开始的秒数，标在章节目录上）。
  - 博客 → 短片（可选）：`film:play`（开播）、`film:seek`（`chapter`：从第几章放）。
- 博客打开短片时可能带 `?autoplay=1`（直接开播；浏览器不允许出声时短片应停在暂停状态，不要静音空跑）和 `?at=<句号>`（从第几句开始）。
- 短片的计时不能只靠 `requestAnimationFrame`：播放器滚出视线、标签页在后台时浏览器不给动画帧，配音会停。用定时器或音频的 `ended` 事件推进。
- 地址带 `?embed=fit`（全窗口放映）或 `?embed=page`（文章里的播放器）时，桥接脚本给 `<html>` 加 `data-embed="fit|page"`。

短片**可以不理会**这些约定，照样能放映：不认 `data-theme` 就按系统深浅色，不认 `data-embed` 就显示完整页面（全窗口里可以滚动）。认了效果更好，做法是在短片的样式里加几行：

```css
/* 嵌进博客时只留播放器；标题、章节、文字稿由博客页面提供 */
[data-embed] header, [data-embed] footer { display: none; }
/* 全窗口放映时，播放器铺满窗口，画面占去控制条以外的全部高度 */
[data-embed="fit"] .player { height: 100dvh; display: flex; flex-direction: column; }
[data-embed="fit"] .stage { flex: 1; min-height: 0; }
```

## 短片必须满足的（`tests/film.test.mjs` 检查）

- 不引用外部样式和脚本（例如 Google Fonts、CDN）：字体服务连不上时整页会白屏十几秒。用系统字体，或者把字体文件放进短片目录。
- 引用的本地文件都存在；有 `poster.png/jpg`；有中英文的短片文章。
- 不直接访问博客页面（`window.parent`、`top.location`）。
- 单个文件不超过 Cloudflare Pages 的 25 MiB 上限（`tests/build.test.mjs` 检查整站）。
- 手机横屏全窗口放映时画面占屏幕一半以上，控制条在屏幕内。
- 原版不是英文的短片，在英文页放映时画面、字幕、按钮里没有中文，配音从英文文件加载；有 `poster.en.*` 时英文页用它。

改动短片时只做必要的修改：上面几条，让 `data-embed`、`data-theme` 生效的几行样式，以及英文版。
